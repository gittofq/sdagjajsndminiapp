# SUARARE // ОЧИЩЕНИЕ ТЕЛЕГРАМА ОТ МУСОРА

Аутентичный старый сайт-визитка (Web 1.0 / 2000s underground card site) для проекта **[SuaRare](https://t.me/suarare)** в чёрно-красной цветовой схеме.

---

## 🩸 Особенности

- **Эстетика старого сайта-визитки:**
  - Никаких нейросетевых генераций и визуального мусора.
  - Настоящий логотип Harold Tree и оригинальный аватар SuaRare с кровавым ножом.
  - Глубокий сплошной чёрный фон (`#000000`), резкий кроваво-красный (`#ff0000`) и белый контраст.
  - Шрифты: жирный классический **Times New Roman** и готический **UnifrakturMaguntia**.
  - Статичная верхняя полоса без бегущих строк.
  - Ретро-разметка карточки-визитки (brutalist tables, borders, `[ НАВИГАЦИЯ ]`).
  - Приближенный, крупный и читаемый интерфейс.

- **Имена создателей (OELIP & SPVOV):**
